# Biblioteca offline

## Baixar

1. Abra o EvoluPersonal pelo endereço HTTPS, conectado à internet.
2. Entre em **Biblioteca** e toque em **Baixar biblioteca offline · 143 MB**.
3. Mantenha a página aberta até aparecer **Biblioteca disponível offline**.
4. Depois, reabra o mesmo endereço no mesmo navegador. O aplicativo e as mídias armazenadas estarão disponíveis sem conexão.

O navegador reserva espaço local para aproximadamente 143 MB de arquivos. A página verifica o espaço estimado antes de iniciar e mostra o progresso. Se o download ficar parcial por falta de conexão, use **Tentar novamente** quando estiver online.

## Observações

O cache fica no armazenamento do site dentro do navegador. Limpar os dados do site/navegador remove o pacote offline. O download precisa ser feito pelo site HTTPS; abrir apenas o arquivo HTML como `file://` não permite instalar o Service Worker.
